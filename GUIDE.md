# Halloween quest

Сайт: https://halloween-quest.buzzzlayter.workers.dev/

## Провести игру

Главная → «Создать / продолжить общую игру». Создайте комнату и покажите каждой из
четырёх команд её QR. Нужны пять телефонов с интернетом, больше ничего.
После подключения всех четырёх команд ведущий начинает игру.

Восемь этапов объединены историей погасшего фонаря. Секретные подсказки распределяются
между командами, капитан меняется, ответ подтверждают все. Ведущий открывает следующий этап
после решения и короткого обсуждения. Полный сценарий — GAME-PLAN.md.

Редактора нет. Тексты и механика меняются в файлах проекта.

Очки видны на всех телефонах: +50 за готовность после обмена подсказками, +100 за
вклад в верный ответ (капитану за план, остальным за проверку), +200 каждой команде
за пройденный этап. На этапах с очередью +50 за своё действие. Ведущий может
отметить настоящую помощь другой команде: +100, один раз команде за этап.
Повторные нажатия, пересмотр ответа и повторное открытие подсказок не дают очки заново.
Подсказку дети передают устно; программа не проверяет речь. Бонус за реальную помощь
подтверждает ведущий. Нет штрафов и мест в рейтинге: есть вклад каждой команды и общая магия.

Для проверки с одного устройства создайте отдельную комнату и до старта включите
«Тест без телефонов» → «Начать тест». Вверху переключайте экран между ведущим и
четырьмя командами. От каждой команды нажимайте готовность, от капитана предложите
ответ, от остальных подтвердите, затем вернитесь к ведущему и откройте следующий этап.
Так можно пройти все восемь этапов без других телефонов. Это имитация ролей, а не
проверка реального подключения по QR. Для игры с детьми создайте новую комнату без галочки.

## Устройство

- `server/scenario.mjs` — этапы, варианты, приватные подсказки и решения.
- `server/game-engine.mjs` — проверка ролей, фаз, готовности, голосований и очереди.
- `server/worker.mjs` — API, Cloudflare SQLite Durable Object на комнату, QR-приглашения.
- `dist/play.html`, `dist/assets/room-*.js` — телефоны ведущего и команд.
- `dist/assets/tasks.js` — только публичные цели, описания и медиа; секретов здесь нет.
- `dist/index.html` — главная и прежние публичные карточки `/?id=N`.
- `scripts/package-site.mjs` — сборка HTML, шрифтов, картинок, видео и публичных QR в publish.
- `publish/game-cards.html` — план без приватных подсказок, пригодный для печати; печатать не обязательно.

Сессии авторизованы случайными токенами. Код комнаты сам по себе не даёт доступа.
Телефон команды получает только её подсказку. Приглашение даёт доступ к соответствующей
команде: не публикуйте командные QR. Ссылку ведущего не надо никому передавать.
Комнаты удаляются автоматически через 6 часов. Это игра, не сервис для хранения персональных данных.

Состояние синхронизируется запросами примерно раз в 2,2 секунды на открытом экране.
При потере сети игра ждёт восстановления; офлайн-режима нет.
Устную коммуникацию и очередность посланников поддерживает ведущий, программа их не распознаёт.

## Проверить и опубликовать

В PowerShell используйте npm.cmd:

```powershell
npm.cmd test
npm.cmd run build
node node_modules/wrangler/bin/wrangler.js dev --local --port 8787
```

В другом терминале, пока сервер работает:

```powershell
node scripts/test-room-api.mjs http://127.0.0.1:8787
```

API-тест создаёт одну тестовую комнату, проводит пять независимых сессий через все этапы
и закрывает комнату. Не печатает токены и приглашения.
Модульные тесты проверяют права, фазы, приватность, однозначность загадок, голосования и UI-контракты.
Они не заменяют проверку интерфейса на реальных телефонах.

Публикация в существующий Worker (не создавайте новый домен):

```powershell
npm.cmd run deploy
```

Первое обновление этой версии создаёт привязку QUEST_ROOMS и SQLite Durable Object QuestRoom.
Существующие комнаты живут до 6 часов. Не удаляйте миграцию из wrangler.jsonc.
Если Cloudflare требует вход:

```powershell
npm.cmd run cloudflare:login
```

После публикации проверьте главную, /play.html, восемь прежних QR и работу пяти телефонов.
Видео могут отдаваться целым MP4 без byte-range; на целевых телефонах проверьте старт и воспроизведение.
Автозапуск со звуком зависит от браузера; кнопка воспроизведения всегда доступна.

## Добавить этап

1. Добавьте объект в ROUNDS в server/scenario.mjs: уникальный постоянный id,
   четыре подсказки, варианты, решение, капитан и правило. Следуйте существующей схеме.
2. Добавьте публичные title/story/goal и медиа с тем же id в dist/assets/tasks.js.
3. Не переносите clues/solution в публичные данные. Не перенумеровывайте существующие id.
4. Запустите тесты и деплой. Каталог, QR, количество искр и комнаты используют массивы автоматически.
5. Менять сценарий желательно между играми, не в середине активной комнаты.

Публичные QR генерируются в Node через qrcode-generator — ручные ссылки и Python для сборки не нужны.

## Архивы

`python scripts/package-deliverables.py` создаёт архив готового проекта и архив рисунков.
Версия с общими комнатами — не только статический сайт: простой drag-and-drop HTML/ZIP
в Cloudflare не развернёт сервер. В архиве есть publish, server, конфигурация и package.json.
Распакуйте, установите npm-зависимости, авторизуйтесь и выполните npm.cmd run deploy.
В архив не попадают токены, .wrangler, .env и node_modules.
