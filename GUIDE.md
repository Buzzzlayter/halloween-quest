# Восемь иллюстрированных заданий

Постоянный адрес: https://halloween-quest.buzzzlayter.workers.dev/

Задания открываются по ссылкам `/?id=1` … `/?id=8`. Первые пять адресов
не изменились: ранее напечатанные QR-коды продолжат работать.

## Файлы

- `artwork/quest-01.png` … `artwork/quest-08.png` — оригиналы генераций.
- `artwork/prompts.json` — восемь промптов; использован встроенный Imagegen.
- `dist/assets/tasks.js` — все тексты, темы, изображения и анимации.
- `dist/assets/images/` — облегчённые WebP для сайта.
- `publish/index.html` — файл для публикации: картинки, стили и скрипты внутри.
- `halloween-site-8.zip` — пакет для ручной загрузки в Cloudflare.
- `halloween-qr-codes-8.zip` — восемь QR в PNG/SVG и лист печати на двух страницах A4.

Анимация выполнена средствами CSS: плавное парение, лёгкое покачивание,
свечение и частицы поверх статических иллюстраций. Это не покадровая
анимация персонажей. При включённом уменьшении движения эффекты отключаются.
В карточках размещены описание героя с картинки и простое командное
задание для детей от 3 лет. Взрослый читает, дети повторяют движения вместе.
Дополнительный реквизит для выполнения не требуется.

## Изменение заданий

Редактируйте `dist/assets/tasks.js`. У каждого задания должен быть
уникальный целочисленный `id`. Чтобы добавить следующее, скопируйте объект,
задайте новый `id`, текст, иллюстрацию и эффект `motion`.

Доступные эффекты: `float`, `flicker`, `watch`, `flight`, `orbit`, `glow`,
`sway`, `bubble`. Для новой иллюстрации положите PNG в `artwork`, например
`quest-09.png`, и укажите `image: "../assets/images/quest-09.webp"`.
Сборка автоматически подготовит WebP и встроит его в итоговый HTML.

## Сборка и ручное обновление

В PowerShell из папки проекта:

```powershell
npm.cmd install
npm.cmd run build
```

Загрузите `publish/index.html` в существующий проект `halloween-quest` через
New deployment. Сохраняйте имя проекта и его домен, чтобы QR не менялись.

## Обновление Cloudflare одной командой

Настройки существующего Worker находятся в `wrangler.jsonc`.
Файлы готовятся для этого же проекта, отдельный домен не создаётся.

Один раз войдите в нужный Cloudflare-аккаунт:

```powershell
npm.cmd run cloudflare:login
```

Вход использует короткий код подтверждения на странице Cloudflare и не
зависит от доступности локального обработчика `localhost:8976`.

Для проверки сборки без публикации:

```powershell
npm.cmd run deploy:check
```

Для сборки и обновления сайта:

```powershell
npm.cmd run deploy
```

Последняя команда публикует изменения в Worker `halloween-quest` в
авторизованном аккаунте. Перед первым запуском проверьте, что это аккаунт
с текущим сайтом. Пароли или API-токены в исходниках не сохраняются.
Вход в Cloudflare по короткому коду и реальная публикация этим скриптом
проверены 18 октября 2026 года. Все восемь QR-ссылок вернули HTTP 200 и
HTML, совпадающий с локальной сборкой.
Позже эту же команду можно подключить к публикации из GitHub.

## QR-коды

Для пересоздания кодов после добавления заданий:

```powershell
python -m pip install --target .qr-tools qrcode zxing-cpp
python scripts/generate-qr.py https://halloween-quest.buzzzlayter.workers.dev
```

Для каждого PNG проверяется обратное считывание ссылки. Для печати откройте
`qr-codes-8/print.html`. Новые ссылки 6–8 станут доступны после публикации
обновлённого сайта. Изменять контент можно без перепечатки QR.

Документация Cloudflare:
https://developers.cloudflare.com/workers/wrangler/commands/workers/
https://developers.cloudflare.com/workers/static-assets/
