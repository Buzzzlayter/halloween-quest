# Сервер на компьютере с публичным IPv4

Этот режим не использует туннель, домен или Cloudflare. Игровой сервер слушает только
`127.0.0.1:3081`; Caddy принимает HTTPS на порту 443 и перенаправляет запросы игре.
HTTP-порт 80 используется для проверки сертификата и перенаправления на HTTPS.

## Что подготовлено

Caddy 2.11.7 для Windows находится в `.cache/caddy-2.11.7/caddy.exe` и не устанавливается
как системная служба. Если кеш отсутствует, скачайте Windows amd64 из официального
[релиза Caddy](https://github.com/caddyserver/caddy/releases/tag/v2.11.7), проверьте контрольную
сумму и распакуйте в этот каталог. Другой совместимый Caddy можно указать через
переменную `HALLOWEEN_CADDY` с полным путём к exe.

Конфигурация явно выбирает Let's Encrypt и профиль `shortlived` для сертификата IPv4,
а не самоподписанный сертификат. IP-сертификаты действуют около шести дней и требуют
автоматического обновления; Caddy должен иметь сохранённые ключи и выход к Let's Encrypt.
Секреты сертификата хранятся в профиле пользователя Caddy, не в репозитории.

## Запуск

В Windows также можно дважды нажать `start-public.bat` и ввести публичный IPv4 по запросу.

Компьютер должен быть доступен по своему публичному IPv4 с портами 80 и 443 из интернета.
Открытие сервера в интернет может быть рискованным: разрешите только необходимые порты,
не публикуйте другие службы и не отключайте брандмауэр целиком.
Когда подключение и настройки будут готовы, в PowerShell из папки проекта выполните:

```powershell
npm.cmd run public -- ВАШ_ПУБЛИЧНЫЙ_IPV4
```

Программа соберёт игру, проверит конфигурацию и запустит оба процесса. Для выпуска
сертификата Let's Encrypt должен самостоятельно подключиться к вашему публичному IP.
Ожидайте сообщения Caddy об успешном выпуске, после чего проверьте на телефоне через
мобильный интернет адрес `https://ВАШ_ПУБЛИЧНЫЙ_IPV4/play.html`. Сертификат должен быть
доверенным, без предупреждений браузера. Не просите игроков обходить предупреждения.

В панели ведущего создайте новую комнату: QR для команд будут указывать на HTTPS-адрес.
Окно PowerShell и компьютер должны оставаться включёнными; `stop-public.bat` или Ctrl+C останавливает оба процесса.
Комнаты сохраняются в локальной базе независимо от Cloudflare.

## Ограничения текущей сети

Если компьютер находится за домашним роутером, прямого подключения пока нет: настройки
переадресации на нём не менялись, и проверка сертификата и мобильного доступа обычно не
пройдёт. При непосредственном подключении к провайдеру также может потребоваться разрешить
входящие TCP 80 и 443 в брандмауэре Windows и убедиться, что провайдер их не блокирует.
Не открывайте порт игрового сервера 3081 наружу.

Сервер пока не проверен на реальном публичном IP и не прошёл внешний аудит безопасности.
Открывать его в интернет и проводить игру стоит только после проверки связи, сертификата,
брандмауэра и нагрузки. Старые ссылки Cloudflare не перенаправляются на компьютер.
