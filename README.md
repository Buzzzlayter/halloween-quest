# Страницы для QR-кодов

> Обновлённая версия: восемь заданий с иллюстрациями. Актуальная инструкция
> по сборке, QR и автоматической публикации — в [GUIDE.md](GUIDE.md).
> Ниже оставлены сведения о первой версии с пятью заданиями.

Исходные файлы находятся в `dist`. Готовая версия для публикации —
`publish/index.html`: текст, стили и анимации собраны в один файл, поэтому
загрузка не зависит от обработки вложенных папок хостингом.

После изменения исходников выполните `node scripts/package-site.mjs` и
загрузите новый `publish/index.html` как обновление существующего проекта.

## Адреса первых пяти заданий

После публикации замените `https://example.pages.dev` своим доменом:

- `https://example.pages.dev/?id=1`
- `https://example.pages.dev/?id=2`
- `https://example.pages.dev/?id=3`
- `https://example.pages.dev/?id=4`
- `https://example.pages.dev/?id=5`

## Как изменить или добавить задание

Все данные находятся в `dist/assets/tasks.js`. Чтобы добавить страницу,
скопируйте объект задания, укажите следующий `id`, новый текст, цвет и тип
анимации. Доступные анимации: `ghost`, `flame`, `eye`, `bats`, `orb`.

Если понадобится обычная картинка, положите файл в `dist/assets/images` и
укажите путь вида `../assets/images/task-01.webp` в поле `image`. Поле
`imageAlt` должно кратко описывать изображение.

QR-коды следует создавать после публикации, когда станет известен постоянный
домен сайта.

Для генерации QR выполните `python scripts/generate-qr.py https://ваш-домен`.
Скрипт берёт все задания из общего файла данных, создаёт PNG/SVG и лист A4,
проверяет обратное считывание каждого PNG и собирает `halloween-qr-codes.zip`.
