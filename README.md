# Тайна погасшего фонаря

Кооперативный Halloween-квест: четыре команды, восемь испытаний, один общий финал.
По телефону на команду и телефон ведущего. Другого реквизита не нужно.

[Открыть сайт](https://halloween-quest.buzzzlayter.workers.dev/) ·
[Создать игру](https://halloween-quest.buzzzlayter.workers.dev/play.html)

## Запуск

Нужен Node.js 22+ и npm. В Windows PowerShell используйте npm.cmd.

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npx.cmd wrangler dev --local --port 8787
```

Откройте http://127.0.0.1:8787/play.html.
Для локального сценария с одного устройства включите «Тест без телефонов» перед стартом.
Для проверки настоящих телефонов создайте комнату на опубликованном сайте без этой галочки.

## Публикация

```powershell
npm.cmd run cloudflare:login
npm.cmd run deploy
```

Цель — существующий Cloudflare Worker `halloween-quest`. Приложение использует
SQLite Durable Objects для общих комнат. Простая загрузка статического ZIP не заменяет деплой Worker.

## Что находится в репозитории

- `server/` — сценарий, секретные подсказки, правила игры и API комнат.
- `dist/` — исходники интерфейса, рисунки и подготовленные видео.
- `Videos/` — исходные видео, сохранённые отдельно от веб-версий.
- `artwork/` — исходные иллюстрации и описания для генерации.
- `scripts/` — сборка, тесты, подготовка медиа и необязательная печать QR.
- `skills/halloween-deploy/` — инструкции и проверка публикации.
- [GUIDE.md](GUIDE.md) — техническая инструкция.
- [GAME-PLAN.md](GAME-PLAN.md) — план игры и объяснение для участников.

`publish/`, зависимости, кэш Wrangler, архивы, временные кадры и секреты игнорируются Git.
Сборка заново создаёт `publish/`; секретные подсказки не включаются в публичный HTML.
Старые адреса карточек `/?id=1` … `/?id=8` сохранены.

## Проверка API

При работающем локальном сервере:

```powershell
node scripts/test-room-api.mjs http://127.0.0.1:8787
node scripts/test-solo-api.mjs http://127.0.0.1:8787
```

Тесты создают временные комнаты и закрывают их после проверки.
Для игры нужен интернет. Воспроизведение видео и сканирование QR проверьте на целевых телефонах.
