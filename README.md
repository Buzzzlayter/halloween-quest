# Halloween Quest

Независимый квест на телефонах: вопросы → коды → вопросы, видео после отправки, очки и помощь команд.
От 1 до числа карточек командных слотов, сейчас до 8.
Игра запускается автоматически, когда подключились все выбранные команды. Кнопка старта не нужна.

[Создать игру](https://halloween-quest.buzzzlayter.workers.dev/play.html) ·
[Инструкция](GUIDE.md) · [План игры](GAME-PLAN.md)

Банк из 48 сюжетных задач хранится в `server/task-bank.json`. При создании комнаты каждая команда
получает 6 своих загадок и 3 случайных кода без совпадений между командами.
Две загадки относятся к привидению, финальные четыре — к шару, тыкве, ключу и зелью.
Это одна история «Тайна погасшего фонаря», а не случайная викторина.
Порядок и число этапов задаются в `server/quest-flow.json`. Старые комнаты сохраняют свои наборы.
Очки настраиваются в интерфейсе при создании комнаты и в панели ведущего.

Эмодзи команд заменены артами из artwork/quest-01.png … quest-08.png.
Привязки заданы в server/team-art.json; сборщик встраивает лёгкие WebP-копии,
поэтому оригиналы PNG не меняются и отдельных запросов к картинкам не требуется.

Ролики каждого этапа идут по порядку, начиная с первого; следующий включается после окончания
предыдущего или вручную. После финиша всех команд у участников и ведущего открывается общий
финал: последние ролики, итоговый рейтинг и повтор всех восьми роликов.

Каждая команда проходит этапы сама. Автопроверка вопросов — по словарю и синонимам, не ИИ.
Ведущий видит засчитанные ответы и прогресс. Команда может начислить другой бонус за подсказку.
«Отправить ответы» окончательно закрывает вопросный этап даже с пропусками и ошибками.
Участник видит верные, неверные и пропущенные ответы; очки даются только за верные.
После отправки доступны продолжение истории и короткий разбор каждой задачи.
До отправки сервер не раскрывает решения и объяснения.

## Запуск

Нужен Node.js 22+ и npm. В Windows PowerShell:

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
npx.cmd wrangler dev --local --port 8787
```

Откройте http://127.0.0.1:8787/play.html.
Для проверки создайте комнату с одной командой и подключите её по QR с телефона — игра начнётся сразу после подключения единственной команды.
На одном компьютере откройте ведущего в обычном окне, а ссылку команды — в приватном.
Это обычная игра без тестовых переключателей. Коды для проверки берите из панели ведущего.

## Проверить и опубликовать

```powershell
node tests/test-room-api.mjs http://127.0.0.1:8787
node tests/test-slots-api.mjs http://127.0.0.1:8787
node tests/test-autostart-api.mjs http://127.0.0.1:8787
node tests/test-solo-api.mjs http://127.0.0.1:8787
node tests/test-answer-format-api.mjs http://127.0.0.1:8787
node tests/test-final-submission-api.mjs http://127.0.0.1:8787
npm.cmd run cloudflare:login
npm.cmd run deploy
```

Цель — существующий Cloudflare Worker halloween-quest, SQLite Durable Objects.
Старые комнаты поддерживаются отдельно; новые получают новый сценарий.
QR /?id=1 … /?id=8 сохранены как прежние карточки/галерея, не как вход команды.

В Git хранятся исходники dist/, server/, scripts/, тесты tests/, исходные Videos/ и artwork/.
publish/, зависимости, архивы, кэш и секреты игнорируются.
Текстовые коды и допустимые ответы — только в серверной конфигурации, не в публичном HTML.
Сами видео остаются публичными файлами. Видео вопросов открываются после отправки при любом результате;
видео кодовых этапов — только после правильного кода.
