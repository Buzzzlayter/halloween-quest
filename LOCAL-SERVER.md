# Игра на своём компьютере

Это отдельный режим: Cloudflare Worker и его комнаты не меняются. Старые QR Cloudflare не перенаправляются.

## Проверка в браузере

Дважды нажмите `test-local.bat`. Он соберёт проект, запустит сервер на
`http://127.0.0.1:3000/play.html` и откроет браузер. Не закрывайте окно запуска;
остановить сервер можно двойным нажатием `stop-local.bat` или через Ctrl+C.
Для проверки команды откройте ссылку в другом браузере или в режиме инкогнито,
чтобы сессии ведущего и команды не перезаписывали друг друга.
Это доступ только на компьютере, не с телефонов через мобильный интернет.

Для доступа с мобильного интернета через публичный IPv4 см. [PUBLIC-SERVER.md](PUBLIC-SERVER.md).

## База и восстановление

База сохраняется в `%LOCALAPPDATA%\HalloweenQuest\rooms.sqlite` на Windows,
вне репозитория и папки OneDrive. На других ОС — `~/.local/share/HalloweenQuest/rooms.sqlite`.
Для другого расположения задайте `SQLITE_FILE`, но не внутри `publish/` или синхронизируемой папки.
Для резервной копии остановите сервер и скопируйте каталог базы целиком;
не публикуйте его, он содержит токены доступа и ответы.
У комнат остаётся обычный срок жизни 6 часов; перезапуск не продлевает его.
